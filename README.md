# Albert M. W. Yau

Scientist-turned-engineer working across **software engineering, data infrastructure, high-performance computing, and scientific Python**, with a background in climate science, physical oceanography, and theoretical physics.

Contributor to open-source projects, including [SciPy](https://github.com/scipy/scipy), [xarray](https://github.com/pydata/xarray), [XLA](https://github.com/openxla/xla), [ducc0](https://gitlab.mpcdf.mpg.de/mtr/ducc), and [torch-harmonics](https://github.com/NVIDIA/torch-harmonics), with a focus on performance, portability, and release infrastructure. Recent work includes optimization of Fast Fourier Transforms (FFTs), Spherical Harmonic Transforms (SHTs), gridding, and SIMD algorithms. Maintains conda-forge feedstocks for [jaxlib](https://github.com/conda-forge/jaxlib-feedstock), [torch-harmonics](https://github.com/conda-forge/torch-harmonics-feedstock), [PyStormTracker](https://github.com/conda-forge/pystormtracker-feedstock), and [spharmgrid](https://github.com/conda-forge/spharmgrid-feedstock).
